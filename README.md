> **개인 동의서 & 약관 리스크 실시간 방어 AI 에이전트**  
> 대한민국 개인정보보호법·약관규제법·공정거래위원회 다크패턴 가이드라인을 기준으로 약관의 위험 조항을 신호등으로 진단하고, 원클릭으로 **필수 항목만 안전 동의**할 수 있도록 돕는 프라이버시 에이전트입니다.

## 🔒 Zero-Retention & 프라이버시 투명성 검증

**ConsentGuard AI**는 사용자의 개인식별정보(주민등록번호, 휴대전화번호, 이메일)를 외부 서버에 전송하거나 저장하지 않습니다.

* **클라이언트 선(先) 마스킹 소스 공개**: [`trust/pii-masker.ts`](./trust/pii-masker.ts)  
  브라우저 단에서 개인식별정보가 어떻게 마스킹되는지 누구나 직접 코드로 검증할 수 있습니다.
* **온디바이스 동의 보관함(Consent Vault)**: 동의 이력은 외부 서버가 아닌 사용자 기기 로컬 저장소(`IndexedDB`)에만 보관됩니다.
* **서버 무저장(Zero-Retention)**: 백엔드는 원문 약관을 영구 저장하지 않으며 정규화된 텍스트의 `SHA-256` 해시만 캐시 키로 사용합니다.
